# 连接部位：从照片判断到可编辑几何

当目标镜头能分辨接口、出线口、护套、软管接头或铰链等连接部位，或用户指出这里不真实时读取。按“承接主体 → 固定/配合界面 → 过渡或活动段 → 相连部件”检查整个组件；远景可简化细纹，仍须保住轮廓、连接和终点。

## 1. 先辨认结构，分开事实与推定

裁出相关照片的局部并保留原图编号、方向和设备状态。有两个以上有效视角时交叉比对；只有单视角时记录不能确认的背面和深度，不声称完成多视角验证。放大不能增加原图证据，AI 补画也不能作为结构事实。

记录：连接两侧的对象、安装面、入口位置与方向、固定段/柔性段、可见终点，以及能确认的比例。把不确定性落实到具体属性：例如“出口方向可确认，槽底是否贯通未知”，不要只给整个部件标一个笼统置信度。

先区分固定出线、可拆插座、密封接头、护线圈与防折件；不能仅凭一个黑色圆圈决定结构。反复出现的明暗条纹可能是环筋、开槽、螺旋或反射，需看外轮廓、槽底、连接桥和相邻视角再决定。

- 照片能确认整体护套时，建立连续基体及其收细/弯曲。
- 照片支持开槽、螺旋或弹簧式防折结构时，保留实际连接路径和空隙，不强行填成实心套管。
- 若结构类型仍有歧义，先用保守轮廓表示；若会改变近景轮廓、配合方式或用户关注点，指出所需的补拍方向/资料，再定型该局部。其他明确部分可继续。

公开厂商资料可帮助理解结构类型和装配方式；除非确认同型号、同版本，不把别款的孔位、尺寸或内部构造移植为目标事实。查不到精确结构时明确视觉推定，不为“更精细”而编造连接件。

## 2. 建立连接约束，再选择构造路线

先建立入口锚点、安装面法线和组件局部坐标；记录相关对象共享的轴线、路径和直径关系。原始照片的视角差异先由审查相机解释，不把每张图的表观弯曲分别硬写成互不相干的坐标。

| 结构 | 共用依据 | 建模时先解决 |
| --- | --- | --- |
| 柔性线缆、软管及随动护套 | 中心路径、局部切线、截面尺寸 | 出口方向、弯曲过渡、固定点、末端 |
| 刚性接头、插头与插座 | 配合轴线、安装面、插入深度 | 法兰/卡扣落座、可见开口、两件边界 |
| 铰链与转轴 | 同一转轴、两侧安装面 | 两端固定、轴节配合、可见间隙与避让 |

这些组件不需要都做成一个网格。要求是连接关系可信、参数变化时相关部分一起更新。只在可见或交付需要时补内部结构；可编辑工程中的隐藏简化应有记录。

## 3. 柔性部件的 Blender 构建步骤

1. **先做路径。** 用少量控制点定义入口、弯曲段、支撑点和终点。入口方向服从参考和接头类型；直出后弯与刚性直角出口采用不同形状。检查曲线自动手柄有无过冲、折点或穿壳。没有规格时只做视觉合理的弯曲，不编造统一的最小弯曲半径。
2. **再做连续形体。** 普通圆线可用 3D Curve 的 Bevel；截面变化可用控制点 Radius 或 Taper Object。整体护套先做基体和端部过渡，再加筋槽；开槽/弹簧式件先做其连接桥或连续螺旋。外观连续不要求所有零件焊成一个实体。
3. **让细节跟随主体。** 护套和线缆的对应段使用同一中心路径或明确关联的路径。可先建直态护套，再用 Curve Modifier 弯曲；检查变形轴、对象原点及相对变换。也可沿路径布置截面/筋：位置取自路径，轴向取自该点切线；不能只移动重复圆柱的中心而保持全部朝向不变。
4. **检查截面与局部扭转。** 沿实际长度分配筋的间距，避免按非均匀曲线参数等分而意外挤成一团。方向需要连续；非圆截面及有连接桥的件要检查 Tilt/扭转。弯曲内侧不应出现无依据的穿插，外侧不应把整体护套拉成断开的环片。
5. **完成根部和出口。** 建立参考支持的孔口、法兰或卡入关系，检查护套与壳体的落座、线缆从护套口进入的关系及粗细过渡。隐藏剖视可用于排除穿墙和假接触。用暗色或 AO 遮住错误不算修复。
6. **再定表面。** 用中性灰和侧光确认形体后再赋予橡胶、塑料或金属材质。保持筋槽在最终像素可读，不靠过强黑缝或任意放大间隙突出结构。

曲线 Bevel、Taper 与 Curve Modifier 的含义见下方 Blender 文档；按所用版本核对界面/API。Fill Caps 只封闭曲线截面，不能把一根截断的线自动变成完整电源线或接头。

## 4. 展示简化仍须有合理终点

若只想减少线缆在画面里的占比，优先整理走线、让它自然延伸出画面或被机身合理遮挡；需要完整展示时保留有依据的终端。不要为补终点凭空增加不明规格的插头。

逐一检查全部交付机位：在一个角度被遮挡的建模截断处，可能在后视或俯视中暴露。完整可旋转模型应解决各可见角度的终点；仅为指定静帧保留的隐藏截断须记录，不能作为完整组件交付。

除非参考或用户明确要求表现剪断、拆解或维修状态，不把裸露截断当作整洁展示的默认做法。若线缆落在地面，检查实际截面与地面的接触和走向，不只凭中心线高度判断。柔性管线须有相应支撑关系，不凭阴影掩盖悬空。

## 5. 局部检查与回退步骤

对目标镜头可辨认的连接部位，保留同机位参考对照、一个补充角度的中性近景，以及最终构图检查。参考仅有单视角时，第二个模型视角用于检查自身几何，不能当作新增参考证据。

| 症状 | 先检查 | 回到哪一步 |
| --- | --- | --- |
| 护套像散落圆盘、线弯了而筋方向不变 | 类型判断、基体/连接桥、筋与路径的关联 | 第 1 节辨认结构；第 3 节第 2–4 步重建 |
| 接头像贴在壳体上或线直接穿墙 | 入口锚点、安装面、孔口与落座关系 | 第 2 节约束；第 3 节第 5 步 |
| 弯曲段突然变细、扭转或互相穿插 | Radius/Taper 组合、相对变换、切线方向与手柄 | 第 3 节第 1、3、4 步 |
| 一换角度就看见断头 | 建模终点、遮挡范围和交付机位 | 第 4 节重新规划走线和终点 |
| 灰模成立，黑色材质下层次消失 | 粗糙度、反射环境、曝光 | 材质/灯光检查，不盲目加深槽或放大筋 |

通过条件：连接两侧可追踪；固定与活动部分关系成立；各交付机位无意外裸露断头、脱节或穿插；不确定的结构已记录。不得以“已加护套”“有六圈纹路”或“已出高分辨率图”代替这些检查。

## 公开资料与适用边界

- [Blender 4.5：Curve Geometry](https://docs.blender.org/manual/id/4.5/modeling/curves/properties/geometry.html)：Bevel、Radius/Taper、Tilt 和 Fill Caps 的操作含义。
- [Blender 4.5：Curve Modifier](https://docs.blender.org/manual/it/4.5/modeling/modifiers/deform/curve.html)：沿曲线变形、变形轴与对象相对位置。官方多语言页面保留了相关英文技术说明。
- [Blender 4.5 Python API：Curve](https://docs.blender.org/api/4.5/bpy.types.Curve.html)：脚本实现时核对曲线属性和版本。
- [Heyco 防拉脱/防折结构选型](https://www.heyco.com/products/strain-relief-bushings/snap-in-cordgrip-strain-reliefs/heyco-strain-relief-selector-tool/)：直出、喇叭口、弹簧式和直角等类型的区别；仅作结构类别参考。

以上资料支持工具用法和结构分类。本文件的建模顺序与验收方法是面向照片重建的工作建议，不是厂商给出的目标设备设计或制造认证。
