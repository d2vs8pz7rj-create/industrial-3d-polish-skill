# 从图片到正式渲染的验收表

选择与本次交付有关的检查项。每个结论应说明所用图片或场景、机位和未覆盖的范围。

| 阶段 | 交给用户/自己检查的证据 | 不通过时返回 |
| --- | --- | --- |
| 图片盘点 | 已编号视角、设备状态、可信尺寸、遮挡与冲突清单 | 补参考/核对尺度 |
| 相机与尺度 | 至少两个视角的粗模叠图或并排图，标出稳定对应点 | 重新校相机或大比例 |
| 初模 | 正侧背与整机三分之四灰模，主要开口和模块分界 | 外形、位置、层级 |
| 制造结构 | 钣金折边、孔、门缝、型材端面和转角近景 | 几何、布尔、法线 |
| 装配 | 支架、铰链、螺钉、密封与功能件的接触近景 | 支撑路径、轴线、穿插 |
| 材质 | 固定中性棚景下的材料分区和相邻角度试图 | 工艺身份、UV、粗糙度/微纹 |
| 灯光与相机 | 同机位改前/改后图，整机及反射敏感局部 | 灯形、角度、环境、曝光 |
| 正式渲染 | 最终分辨率和 100% 细节裁切 | 采样、降噪、纹理过滤 |
| 交付 | 重新打开工程、资源可用、版本与设置记录 | 打包/路径、活动场景与相机 |

## 单轮改进记录

- **可见现象**：在哪张参考或渲染的哪个部位，具体错在哪里。
- **依据与置信度**：CAD/实测、多个照片、单张推断，分别标明。
- **原因假设**：尺度/相机、几何/法线、装配、材质、反射环境或成像。
- **本轮修改**：对象和改动类型；哪些已认可的部分保持。
- **对照结果**：固定机位的改前/改后；相关相邻角度是否也成立。
- **剩余限制**：不可见内部、未测尺寸、未验运动、未做工程受力等。
- **输出记录**：源版本、Blender/引擎、计算设备、色彩管理、分辨率、采样/降噪、资源状态和文件哈希。

## 何时结束一轮

目标问题在实际输出中消失或明显改善，至少一个相邻视角不退步，已认可结构没有被意外改动，最终源文件能重新打开且资源完整，就结束本轮。继续加细节、灯、采样或渲染整段动画，需要有新的可见问题或明确需求。不能因为脚本成功、节点变多、渲染时间更长就宣布“更真实”。

若照片与尺寸互相矛盾，先指出冲突以及它会影响哪些可见结构。给出可审查的候选或请求关键尺寸，不能静默选择对单张图片最好看的变形。
