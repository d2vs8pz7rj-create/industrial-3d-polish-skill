# 阶段验收与交付记录

每个结论应带可查看的场景/图片、相机和覆盖范围。脚本执行成功、零件数量增加或采样提高都不是“更真实”的证据。

## 阶段门槛

| 阶段 | 必须能看到的证据 | 不通过时返回 |
| --- | --- | --- |
| 输入 | 已编号的多视角照片、状态、可靠尺寸、遮挡与冲突 | 补拍或明确推定 |
| 校准 | 同一粗模对齐两个独立视角，关键点和外轮廓有依据 | 相机、畸变、尺度 |
| 灰模 | 正侧背顶和斜视图，主要开口与模块层级正确 | 外形、位置、深度 |
| 制造 | 板厚/折边/转角/通孔/分件缝的中性近景 | 几何、拓扑、法线 |
| 装配 | 紧固件落座、铰链、支架、导轨、连接部位中性近景，必要时接触剖视 | 支撑路径、配合关系与干涉 |
| 材质 | 固定棚景的分类样板，正面及相邻斜视成立 | 工艺、UV、微纹 |
| 光影 | 同机位前后图，反射和接触影不遮关键结构 | 灯形、环境、曝光 |
| 正式图 | 整机、关键近景、最终尺寸 100% 裁切 | 采样、降噪、过滤 |
| 工程 | 重开模型与打包资源，活动相机/灯/输出设置正确 | 路径、版本、缺资源 |
| 实时交付（若需要） | 最终平台实拍或截图及性能记录 | 材质迁移、反射或网格优化 |

## 受保护的基线

第一次修改前保存已认可的版本、相机和参考图。关键对象记录世界空间包围盒、中心、朝向、主要开口和相对位置；有必要时保存网格或材质哈希。局部改动后对比这些值和同机位图，找出非目标变化。遇到比例漂移时先恢复或解释，不要把错位归因于相机而跳过。

把变更分为相机/尺度、几何、装配、材质、棚景和渲染。每轮一个主要目标；为了保持装配而联动的相关零件需要同时列出。已认可的屏幕内容、标识、设备布局和光影样式应有可审查的改前图。

## 必查的不同视图

- 整机：前斜与后斜，能看到整体比例、色块节奏和大面积反射。
- 正交：前、侧、背、顶，能发现照片透视误导和局部比例漂移。
- 近景：门角与缝、孔与螺钉、铰链/支架、导轨/拖链、透明件/屏幕、精密件与托座。
- 运动（若有）：起点、中间、终点，检查父子运动、避让、线缆与支撑路径。
- 最终像素：文字、细纹、玻璃边、细缝、薄件、噪点和降噪损失。

只有静态图需求时无需模拟完整运动；但可以开启的门或明显的滑台至少不能有显见的静态穿插。正式图若只验证一个镜头，就明确说明其他视角没有覆盖。

## 可辨认连接部位的检查

接口、护套、软管或铰链出现在目标近景或受到用户关注时，按 [连接部位建模与检查](connections-and-flexible-parts.md) 留下局部对照与补充角度，核对结构类型、安装/配合界面、连续路径或共轴关系及末端。只有一个参考视角时，注明第二个模型视角仅检查自身几何。

展示简化后逐一检查全部交付机位，确认无意外裸露截断、脱节和穿插；仅为指定静帧隐藏的截断须记录适用范围。整体护套应有连续基体，开槽/弹簧式结构应有相应连接路径，不将某一种构造强加于全部防折件。结构类型仍影响关键近景而无法确定时，保留推定并指出缺少的证据。

## 交付

重开最终 Blender 工程，确认图片、字体及外部材质路径可用。交付可编辑工程、主要检查图、正式渲染和上述记录；注明真实尺寸、照片推定尺寸及纯展示性细节。若交付到别的电脑，选择打包资源或清楚的相对路径，并在目标环境重新打开验证。视觉模型的可信度与工程制造可行性是不同结论，分别陈述。
