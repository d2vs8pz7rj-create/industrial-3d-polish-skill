# 从照片到可编辑几何的操作方法

从图片开始建模，或已有粗模需要重新解释照片时读取。这里补足照片解读、相机匹配、尺寸关系、Blender 构造路线与表面资料提取；制造与装配细节继续按 geometry-and-assembly.md 执行。

## 1. 先建立部件地图

保留原始照片，另做标注副本。每张图标出主体轮廓、面板边界、开口、突出/凹入部件、连接件、轴线及疑似反射/阴影。给同一部件稳定编号，在其他图片中寻找对应；用“清楚可见、部分遮挡、完全不可见”记录覆盖范围。

建立表：部件编号、参考图与区域、可见边界、候选工艺/形体、邻接或固定对象、关键尺寸依据、未定项。表中记录当前项目的具体信息；不把这些记录放进通用技能包。

遇到一条黑边，先保留门缝、密封条、槽口、阴影等候选解释。通过侧视的深度、其他图的连续性、开门状态和局部近景判断；亮暗变化只能作为线索，不单独证明结构。反射中的部件不直接建成镜面背后的实体，模糊的零件不要用猜出的复杂轮廓替代证据。

先恢复影响剪影、模块布局、开口与装配的部件。被遮挡的深度保留可调代理体；不足以区分的候选结构标为推定。需要补图时说明具体部位和角度，例如“沿门侧拍一张能同时看到门厚与门框的图”，而非笼统要求更多照片。

**输出**：标注图、跨图片部件对应表、少量结构候选，以及可以开始建模的主体清单。

## 2. 相机与模型交替匹配

每张透视照片使用独立的匹配相机，所有相机观察同一套几何。确定图片原始比例、可靠尺度、坐标和对应点；先用简单柜体或体块，暂时不建微细节。

按以下循环推进：
1. 用可靠尺寸和最有约束力的视角确定粗模的大比例；没有绝对尺寸时明确采用相对尺度。
2. 固定粗模，调整某张图的相机朝向、位置、透视和画幅，使主要角点与长边尽量对应。透视图优先匹配边线方向和近大远小关系，再细调构图。
3. 固定匹配相机，调整多张图都支持的几何尺寸与模块位置。不要为改善某一张图自由变形局部。
4. 回查其他照片相机，记录未对齐区域与可能原因，重复至大形可解释主要投影。

所有对应点表现相似偏差时，优先检查相机、裁剪、畸变和整体变换；只有局部偏差时再检查部件尺寸、状态或遮挡。此规律只是排查线索，整体比例错也会造成普遍偏差，必须与独立尺寸及其他视角交叉判断。

焦距与拍摄距离、几何深度与视角之间可能有多个近似解。证据不足时保留合理解和推定项，不声称单张图恢复了唯一正确形体。透视校正后的面片仅用于该平面的图案或尺寸线索，不能当整台设备的正交图。

**输出**：照片匹配相机、同粗模的多视角叠图、相机设置及剩余几何歧义。展示相机在此后另设。

## 3. 建立尺寸关系骨架

先在项目记录或建模脚本中集中管理总宽深高、主要分层、开口边界、面板厚度、安装面与关键轴线。用可信尺寸锁定高置信项，照片推定项保持可调。无绝对尺寸时先记录相对关系，得到尺寸后再整体定标。

给每项尺寸标明关系类型：
- **固定尺寸**：有来源的标准部件、板厚或孔径，主体放大时不自动放大。
- **边界依赖**：门板尺寸取门洞尺寸与间隙之差，开口或柜体更新时重新计算。
- **定位依赖**：把手、铰链和螺钉相对门的局部安装面定位。
- **比例推定**：缺证据的模块深度暂按相对比例建立，随后接受补充资料修正。

在 Blender 用局部坐标、父子关系、Empty 或可重复的构造脚本组织关联件。注意父对象缩放可能连带改变固定零件尺寸；采用参数重新计算、单独管理尺度或其他明确方式处理。不要通过缩放整个门组件使标准紧固件一起变大。

让关键参数有一个明确来源，避免同一门洞宽度在多个对象或脚本中各写一个值。每次参数更新后重建依赖部件，检查接触与原本已确认的轮廓。保留手工例外和真实不对称项。

**输出**：尺寸/依赖表、安装面与轴线、可恢复的大形基线。此骨架支持视觉模型修改，不构成制造尺寸认证。

## 4. 选择 Blender 构造路线

先让粗件有正确位置和占地，再用可编辑的结构替换。保留适当的修改器、实例或构造参数，直到确定无需继续调整；复杂的修改器堆叠不能代替清楚的零件结构。

| 部件 | 可采用的构造路线 | 容易出错的位置 |
| --- | --- | --- |
| 平直薄板 | 建板面轮廓，按实际厚度挤出或用 Solidify；随后处理开口和小倒角 | 厚度向内/向外的位置、孔内壁、窄区域自交 |
| 折边面板/托盘 | 对明确的直线折边建截面再挤出；多边折返或复杂角部用明确拓扑建连续内外面 | 返回边、角部收口、双层补片、折边穿插 |
| 型材或长导轨 | 按截面挤出，端部独立处理，连接件按安装面定位 | 端面、轨与滑块分工、轴线和装配深度 |
| 机加工支架 | 从承载体量建立安装面，切除有依据的孔槽，再做工艺对应倒角 | Boolean 破面、孔口法线、薄壁、实际承接 |
| 圆盘/环/旋转件 | 按截面旋转或建立足够分段的圆形实体，独立处理缺口和侧面 | 厚度、低分段轮廓、无支撑、表面图案代替槽 |
| 紧固件与重复孔位 | 建一个符合目标镜头的母件，按孔位和安装面实例化；方向遵循局部法线 | 头部落座、接收面、镜像方向、间距与例外项 |
| 拖链/线缆 | 先建可信节段或截面，再安排路径与端点；按需求使用实例、曲线或独立节段 | 接头、段间空隙、弯曲连接、端部固定及运动穿插 |

Boolean 用于目标形体确实需要的切除；后续若出现塌面、异常阴影或角部反复修补，先查刀具、尺度和拓扑，再选择明确建面的路线。Bevel 的大小由部件尺度、工艺和目标镜头决定；平滑与法线处理应保持平面和真实硬边。修改器顺序按实际几何和着色结果选择，不套用全机固定模板。

重复件共享合理的母件，保留有证据的差异。只在近景需要时细建头部槽、密封唇或链节内部；几何精度按最终可见轮廓、接触和像素决定。

**输出**：可编辑部件、构造方法记录，以及薄板角部、孔、接触和重复件的近景。

## 5. 从照片提取表面资料

优先使用用户提供的原始 Logo、屏幕内容和图案。只有照片时，保留原图并导出独立派生素材，记录图片编号、裁取区域、透视变换、清理与重建范围。

对于平面标识或显示面：
1. 确认四角或其他足够的平面对应点，把斜拍区域校正到平面。
2. 用已知物理尺寸、原始内容或可信比例设定输出纵横比；四角拉成任意矩形不能恢复真实比例。
3. 裁除边框遮挡，处理明显的现场阴影与高光，并注明修改。过曝、模糊或被遮住的信息无法可靠恢复时请求原素材或标记近似。
4. 以真实尺寸贴到对应面；检查字向、颜色空间、UV、板缝、远景过滤和斜视可读性。

把涂装图案与现场光影分开判断。对比同一部位的多张照片：稳定的图案边界、随视角改变的亮带、阴影投向、工艺方向共同提供线索。不要把照片中的反射烤成永久材质图，亦不要从一个亮像素推定材料物性。曲面标识需要相应曲面映射，不能用单个平面校正处理整片曲面。

材料工艺继续用固定灯光小样拟合；从照片提取的表面图案与拟合出的反射参数分别记录。照片无法确认的文字和内部内容明确留缺或经用户同意近似，不能将自动补全当原始事实。

**输出**：可用的图案/内容素材、来源与编辑记录、UV 映射，以及需要补充的资料。
