# 写实问题的排查路径

渲染“像玩具”不是单一参数问题。先在固定相机下描述具体可见症状，再做最小隔离试验。表中“优先检查”是排查顺序，不是唯一原因；找到原因后只改相应模块，并回查相邻角度与整机。

| 可见症状 | 优先检查 | 可执行修正与验证 |
| --- | --- | --- |
| 整机像压扁/拉长，局部虽然精致 | 相机视角、图片裁剪、尺度锚点、全局变换 | 用正交正侧图和两个独立照片比特征点；锁定已确认包围盒后再细化 |
| 门缝像画上的黑线 | 面板是否真实分件、厚度、返回边、框与门的深度 | 掠射光和侧视检查视差；缝应在角落连续并与装配逻辑一致 |
| 孔像贴了深色圆片 | 通孔深度、内壁、背面残留面、Boolean 法线 | 剖视或射线穿透检查；删掉假孔片，建立实际开口 |
| 白色板角像塑料肥边 | 倒角过宽、法线断裂、灯带宽度、反射卡位置 | 用中性材质和单灯隔离；缩窄错误倒角并检查平面是否保持 |
| 浅色板像没有体积的白纸 | 曝光、环境单调、主光梯度、粗糙度 | 加入可读明暗带，保留面转折；不要只把板改灰 |
| 所有金属像同一种灰塑料 | 工艺分类、金属身份、反射环境、加工方向 | 分类做样板；放入亮暗卡，并看相邻视角高光如何移动 |
| 玻璃一片白或黑洞 | 是否有厚度和框、反射卡覆盖、透射/粗糙度、内部照明 | 固定玻璃参数先移动灯卡；正面及斜角都检查内部可读性 |
| 屏幕被反光盖住或内容失真 | 内容比例、UV、盖板厚度、发光和反射叠层 | 保留原内容，重新排光；正面及邻近斜角检查文字 |
| 支架/托盘看似浮着 | 承载面、固定孔、连接路径、接触影 | 隐藏外壳看剖面；补实际承托与落座，不靠 AO 涂黑 |
| 螺钉歪、悬空或没有接收孔 | 局部法线、安装面、头型与孔型 | 对齐轴线、建立接收几何；近景和侧视验证 |
| 机械部分像重复积木 | 导轨/滑块/限位、丝杠支撑、夹具压力路径 | 用有功能的完整组件替换无意义重复块；检查运动关系 |
| 拖链像实心软管或方块 | 节段、铰接、横梁、内部空隙、端部固定 | 建可读截面及两端支座；在弯曲状态检查避让 |
| 护套像一串圆盘，筋不随线缆弯曲 | 结构类型、基体/连接桥、局部切线和路径关联 | 按 [连接部位指南](connections-and-flexible-parts.md) 建连续形体或实际开槽/弹簧结构，再沿共用路径布置细节；侧视与斜视检查 |
| 展示线缆像被剪断，换角度就露断头 | 终点处理、遮挡范围、交付机位 | 重排走线或保留有依据的终端，检查全部交付视角；封住截面不能代替终端 |
| 精密薄件像纸片 | 厚度、边缘、缺口、支撑和实际间隙 | 加真实几何与托座；正面和低角度近景检查 |
| 局部细纹在远景变脏或闪 | 纹理世界尺度、UV 拉伸、过滤和法线强度 | 降低频率/强度或预过滤；最终像素 100% 检查 |
| 同心亮圈或拉丝像机器画出的图案 | 各向异性过强、纹理方向突变、光源太尖 | 回到无纹样板，逐项恢复；斜视检验自然程度 |
| 只有一个英雄角度成立 | 单张图驱动的几何、反射捕获范围、灯位、隐藏穿插 | 增加正侧背、相邻角度和局部剖视；修源问题 |
| 更新局部后整机比例或其他零件漂移 | 世界变换、父子关系、对象复用、脚本副作用 | 对比基线包围盒、关键点和已认可机位；恢复非目标变动 |
| Cycles 好看，实时预览失真 | 光照模型、反射方案、纹理方向、色彩管理、法线切线 | 在目标平台重建近似并逐材质校验，不能只导出网格就宣布完成 |
| 降噪后细缝/文字消失 | 采样不足、亚像素细节、纹理过滤或降噪强度 | 对照未降噪裁切，适当提高可见尺度或采样，重验目标尺寸 |

## 单轮诊断格式

1. 现象：指出机位、对象、像素区域和预期依据。
2. 候选原因：分别列相机/比例、几何/法线、装配、材质、光/反射、纹理/成像；排除显然不相关项。
3. 隔离试验：例如灰模排除材质、单灯排除复杂棚景、剖面排除假接触、相邻角度排除视角偶然。
4. 最小修改：只改当前原因簇，保留认可的结构、屏幕内容与相机。
5. 证据：同机位前后图、至少一个相邻视角、整机图及需要时的最终像素裁切。
6. 结论：明确解决了哪个症状，哪些假设仍未验证。
