# 从照片建立可编辑模型

在输入主要是照片、截图或产品图时读取。核心是恢复可见几何的约束，不让单张照片的投影误差变成整机形变。

## 1. 建立证据地图

给图编号，记录视角、拍摄状态、可见面、焦距或广角迹象、裁剪、分辨率、遮挡、反光和可能的后期修图。门开闭、护罩拆装、不同配置和不同生产批次分别标记，不能把不同时态的边界合成一个状态。

把已知尺寸与待求尺寸分开。至少找一个可信尺度锚点；有第二个独立尺寸时交叉检查。用表格标记每个关键特征：在几张图中可见、尺寸依据、候选解释、置信度、是否影响外轮廓或装配。没有图的背面与内部可先只做必要体量，低置信度结构在交付中标注。

优先取得正、侧、背、顶与斜视图，以及门缝、孔、铰链、支架和底座近景。不要把生成图片、镜面反射或屏幕画面当真实结构证据。

## 2. 校准相机与参考图

在 Blender 统一单位、竖直轴、前向和原点。保持图片原始纵横比。正交图用作比例约束；透视图先估消失线、相机高度、方位和视角，再匹配模型。广角明显时先校畸变或降低该图的尺寸权重。

在多张图里标同一批稳定对应点：外轮廓角、层间界、门轴、孔中心、开口角、底座接地点。避开阴影边、高光边、透明件里的反射和模糊倒角。先调相机参数与模型整体比例；不要为贴合单张照片把柜体局部任意拉伸。

可用叠图或并排图反复比较：
- 正视检查宽度、横向中心、开口与面板节奏。
- 侧视检查深度、悬挑、铰链轴和底座关系。
- 顶视检查模块占地与前后错位。
- 斜视检查厚度、遮挡、角点和突出件。

如果两图冲突，先查拍摄状态、透视、裁剪、镜头畸变或不同配置；再决定几何需要改哪里。保留冲突记录和候选解释。

## 3. 粗模和比例锁定

先用少量代理体建立主体、底座、顶部、门、操作区和显著外设。按外轮廓 → 大开口 → 大面板 → 凸出/内凹 → 局部结构建模。每一步输出灰模，避免材料和灯光掩盖比例问题。

以可信尺寸设全局尺度，随后核对总宽深高、各模块中心、地面接触和主要开口。用正交视图检查对称；真实不对称必须有图片支持。给主要对象稳定命名和集合，门、抽屉、线缆、机构与承载件保持可单独编辑。

已有模型的迭代先存基线：世界空间包围盒、对象变换、关键点坐标、灰模截图和来源版本。修改局部件后复查全局外轮廓。相机调整与几何调整分别记录，不要把模型整体比例偏移解释为“只是视角变了”。

## 4. 从投影转向可制造几何

照片只给可见投影。检查每一处深度：门是否有厚度和框、面板后是否有返回边、开口内是否有壁和承载件、突出的台面如何支撑。真实分件应在侧视或掠射光下有视差和阴影，不靠黑色线条伪装。

隐藏侧可参考对称侧作暂定，但不自动复制全部孔、标识和连接件。可动件明确轴线、父子关系和活动范围。之后按 [结构与装配](geometry-and-assembly.md) 精修。

## 5. 进入材质前的灰模门槛

至少检查正、侧、背、顶、两个斜视以及关键近景。同一粗模应解释至少两个独立照片视角，主要尺寸与可靠证据不冲突，门/支架/开口在三维中有合理深度。仍未知的部分清单化，不需为了完成灰模虚构内部细节。
