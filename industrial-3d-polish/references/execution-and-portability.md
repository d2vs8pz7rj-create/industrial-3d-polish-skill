# Agent 执行与跨电脑复现

在新项目开始、从粗模接手，或需要把成果交到另一台电脑时读取。前面的参考文件解释怎样建模和判断真实感；本页规定怎样把那些判断变成可复查的 Blender 工作结果。

## 1. 先建立本次任务契约

确认五类输入：获授权的图片/视频、已知尺寸或 CAD、现有 Blender/其他 3D 文件、已认可的画面、最终用途与输出尺寸。检查 Blender 是否可运行、版本与可用渲染后端、机器可承受的试渲染规模。缺少 GPU 不阻止建模，可用当前可用后端做样图并重新估算正式渲染成本。

分三种起点：
- **只有图片**：先编目、校准和灰模。单张图片无法确定背面与深度，明确保留推定项；若缺口会改变外形或关键装配，提出具体补拍角度或尺寸，同时继续可确定部分。
- **有粗模**：先记录世界空间尺寸、对象变换、相机、材质与截图，再针对错误部位修改。不要为方便重建而丢掉已认可结构。
- **有 CAD/工程图**：把尺寸和装配图作为优先几何依据，仍用实物照片核对可见版本、装饰面、工艺与状态。CAD 和照片冲突时记录可能的配置差异。

开始前确定交付是静态图、可编辑 Blender 工程、实时模型还是动画。目标用途决定细节的几何/纹理分配与检查范围。

## 2. 组织可恢复的工作

把参考素材、工作工程、试渲染和最终交付分开保存；不要改写原始参考图。给主要照片和关键对象稳定编号或名称，避免“第 3 张图”“这个圆柱”在后续轮次变得含糊。每个阶段保存可回退的工程版本及同机位图；仅保存最终漂亮图片无法追踪比例或材质何时退步。

维护一份简短记录，至少包含：输入来源、可靠尺寸、推定项、坐标/单位、当前基线、目标镜头、已确认画面与本轮修改范围。照片或模型若有限制使用范围，不把原图、Logo、模型、文件路径或派生图上传到通用公开 skill 仓库。

## 3. 在 Blender 中逐阶段操作

| 阶段 | Agent 应做的事 | 进入下一阶段的证据 |
| --- | --- | --- |
| 参考校准 | 按原始比例放参考图，区分正交与透视，设置单位和前向；建立对应点及照片匹配相机 | 同一粗体块在至少两个可用视角解释外轮廓；单图任务注明深度推定 |
| 大形 | 用少量可编辑体块建主体、门、开口、底座和显著外设；分集合管理可动/可拆件 | 正侧背及斜视灰模；关键尺寸与高置信证据一致 |
| 结构 | 在目标镜头可见处建立厚度、折边、真实孔、支撑和紧固件承接；按需使用 Boolean、Bevel 和法线处理 | 掠射光近景、剖面及侧视排除假缝、假孔、浮件和破面 |
| 装配 | 确认承载、固定、导向、线缆终止和运动避让；关联件同轴、同动 | 关键接触近景；若可动，检查起点、中间、终点 |
| 材质 | 按工艺分组，固定相机/中性灯做小样；核对贴图颜色空间、UV 和实际纹理尺度 | 整机材料分区清楚，近景及相邻视角没有明显塑料感或闪烁 |
| 棚景 | 保留审结构相机，另定展示相机；主光、补光、环境与反射卡逐步加入 | 明暗描述体积，屏幕/标识可读，反射不遮目标结构 |
| 渲染 | 先低成本试图，再按目标尺寸测样；确定设备、采样、降噪与色彩管理 | 整机图、局部图、100% 像素裁切及实际渲染日志 |

表中步骤可因输入情况重排，但每次跨过一个阶段都应有可看的图或工程证据。没有运行 Blender 或没有实际出图时，不能宣称模型/渲染已完成；应准确说明已完成到哪个阶段。

## 4. 控制每轮改动

每轮选择一个可见问题：写下参考依据、可能原因、隔离试验、目标对象和保持不变的基线。相机、几何、材质、棚景、采样分别处理。灰模错误先修几何；反射大白带先查灯形与环境；最终像素的细纹闪烁先查尺度和过滤。

输出固定机位改前/改后，以及一个能暴露副作用的相邻视角。若局部改善但整机比例、材质层次或已认可画面退步，不能把本轮标为通过。问题已解决且相关视角稳定就停止这一轮，不为“更精细”无依据地增加对象。

## 5. 跨电脑复现检查

保存最终工程后，审计所有图片、字体、HDRI、链接库、缓存与其他外部依赖。能打包的资源在保存后确认确实进入工程；不能打包的资源随交付放在有说明的相对路径。不要以“点击了打包命令”代替缺失资源检查。

从最终保存的文件重新开启 Blender，检查活动场景、相机、灯、单位、材质、贴图、色彩管理和输出设置。尽可能在新进程或目标电脑用保存文件重渲染一张代表图；记录 Blender 版本、渲染引擎、实际设备、分辨率、采样、降噪、耗时与源文件哈希。CPU/GPU 不同可能使耗时和少量像素不同，验收以结构、材料身份、反射、光影和关键细节是否一致为准。

交付包括可编辑工程、必要资源、参考来源与推定项清单、关键阶段检查图、正式渲染，以及能够在另一台电脑找到活动相机与重渲染设置的简短说明。实时平台另按对应参考文件验证，不能仅凭 Blender 静帧通过。
